# Tech Classroom

Classroom materials for Digital Technologies lessons: slides, interactive demos, Scratch files and worksheets. Every page is static and runs in the browser. There are no logins and no data is collected.

**Live site:** https://razer-chan.github.io/tech-classroom/

| Course | Link | What's inside |
|---|---|---|
| Cyber Safety | [cyber-safety/](https://razer-chan.github.io/tech-classroom/cyber-safety/) | Slides for privacy, passwords, password reuse + MFA, and phishing. Use alongside Grok Learning "Information Privacy and Security – Secondary" |
| Scratch | [scratch/](https://razer-chan.github.io/tech-classroom/scratch/) | 4 lessons (40 slides) with interactive demos. Each `Lesson …` folder has the `.sb3` files; Lesson 4 has the debugging worksheet and the fixed teacher version |
| Hardware | [hardware/](https://razer-chan.github.io/tech-classroom/hardware/) | 5 lessons with 3D models; 4 self-marking activities (students download a result file); PC Build Project with the Word planning sheet in `downloads/`; teacher results page at `#/results` |
| Edison Robot | [edison-robot/](https://razer-chan.github.io/tech-classroom/edison-robot/) | Maze task brief, 10-step scoring, 3D step-by-step demo |
| SPIKE Robot | [spike-robot/](https://razer-chan.github.io/tech-classroom/spike-robot/) | LEGO SPIKE Prime Cargo Arena: task brief, 8 steps / 10 points, 3D step-by-step demo |
| SPIKE Prime Quiz | [spike-quiz/](https://razer-chan.github.io/tech-classroom/spike-quiz/) | 20 self-marking questions. Students type any name, see their score and download a result file (TXT) to hand in. Teacher page [spike-quiz/results.html](https://razer-chan.github.io/tech-classroom/spike-quiz/results.html) re-marks a class's files and exports CSV |
| Noongar Keytag | [noongar-keytag/](https://razer-chan.github.io/tech-classroom/noongar-keytag/) | 5 slide lessons: Noongar six seasons, motif breakdowns, keytag templates to download, Inkscape steps. Reference artwork and symbol posters are credited to their creators |

On a projector: ← → change slides, **F** for full screen. Students load `.sb3` files in Scratch with **File → Load from your computer**.

The `scratch/`, `edison-robot/`, `spike-robot/`, `spike-quiz/` and `noongar-keytag/` folders also work offline: download the repo and double-click `index.html`. `hardware/` works from any web address, including a renamed fork or a custom domain. `cyber-safety/` is a Next.js export built for this site's address, so it needs to be served from here.
